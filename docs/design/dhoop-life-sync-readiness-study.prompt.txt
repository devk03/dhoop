Advanced connection details collapsed. All demo data clearly labelled outside panels. No debug walls, no tokens, no placeholder technical paragraphs, no oversized diagnostics, no claims a queued message was delivered, no fake Live success. Existing app design, not new branding. Polished minimal efficient controls with immediate pressed/pending/result feedback.
